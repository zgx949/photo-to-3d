# 参考图提示词样例

四种风格，均按"可建模"标准写：单主体、全身、纯背景、四肢分离、服饰简化。直接替换 `{风格}` 之外的措辞也可以，但**这六条约束尽量保留**。

## 通用骨架

```
把照片转成{风格}卡通角色参考图，用于 3D 建模：
只保留一个人，正面或 3/4 侧视角，全身入镜完整呈现头到脚，不裁切；
纯浅灰或白色无缝背景，无场景无地面阴影，无文字、水印、边框；
四肢与身体分开、轮廓清晰不粘连，手指自然并拢或张开，不交叉；
服饰简化为清晰大色块，去掉细碎纹理、褶皱、镂空和多余挂件；
保留脸型、发型、体型、服装配色等身份特征，一眼能认出是本人；
均匀柔和的正面光，哑光手办质感，主体居中并留少量边距。
```

## 1. Q 版潮玩（成功率最高）

风格词：`Q版潮玩手办风，三头身，圆润夸张的比例，哑光树脂质感，大头小身`

适合：做手办、盲盒、桌摆。形体简单、面数可控，3D 最稳。

## 2. 二次元 / 国漫

风格词：`清透二次元国漫风，平涂阴影，发丝成组块状，服饰轮廓干净`

适合：角色立绘转模型。注意要求"发丝成组块状"，否则细发丝在 3D 里会碎成噪点。

## 3. 扁平贴纸 / 潮玩 IP

风格词：`扁平插画贴纸风，粗描边，纯色块，极少渐变，正视角`

适合：做低面数模型、贴纸、表情包衍生。立体感弱，但轮廓最干净。

## 4. 写实偏卡通的"三渲二"

风格词：`三渲二写实卡通，保留真实人体比例，柔和赛璐璐上色，细节适度简化`

适合：想要"像本人但不吓人"的用途。风险最高——比例接近真人时，脸容易崩，建议出图后放大看轮廓。

## 不合格的常见症状与对应修法

| 症状 | 改法 |
|---|---|
| 不像本人 | 加"保留脸型、发型、体型等特征，一眼能认出是本人"，并降低风格化强度 |
| 背景没清干净 | 明确"纯白或浅灰无缝背景，无场景、无地面阴影、无投影" |
| 缺脚 / 半身 | 强调"全身入镜、从头到脚完整、不裁切"，必要时改纵向构图 |
| 手指粘连、手臂贴身 | 加"手臂与躯干分开、手指并拢不交叉、轮廓不重叠" |
| 衣服细节太多 | 加"服饰简化为大色块，去掉纹理、褶皱、镂空、挂件、图案文字" |
| 面部有强阴影 | 加"均匀柔和正面光，无强投影、无高光溢出" |

## CLI 示例

```bash
# 先只校验参数，不花钱
python3 scripts/ark_3d.py create --image ./cartoon-ref.png --dry-run

# 确认后正式跑：默认 obj（自带 mtl 与贴图，打印 / 上色链路直接可用）
python3 scripts/ark_3d.py run --image ./cartoon-ref.png --out ./out --format obj --level high

# 仅网页 / Unity 预览场景才要 glb
python3 scripts/ark_3d.py run --image ./cartoon-ref.png --out ./out --format glb --level medium
```
