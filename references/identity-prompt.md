# 参考图相似度控制（像不像本人）

这一层决定了最终 3D 像不像。流程是固定的四步：**先分割 → 填特征表 → 出图保姿势 → 并排验收**。跳过任何一步，相似度都会掉。

## 1. 先做人物分割，再谈风格

原片里的背景、地面反光、路人、杂物会被图像编辑模型当成角色的一部分（尤其是深色裤子贴深色背景、浅色衣服贴白墙时，边界会糊）。先把人抠出来，边界唯一，后面只处理主体。

```bash
mediakit-cli image remove-image-background \
  --image-url <本地路径或公网URL> --scene human --need-crop-background=true
```

- 输出是透明 PNG，返回字段 `image_url` / `image_width` / `image_height` / `image_size`。
- 这是**中间产物**：直接喂给下一步 `image_edit`，不要展示给用户、不要在正文贴它的链接。
- 原图 < 10 MB、长边 ≤ 7680 px；超了先 `resize-image`。
- 抠图不可用（命令报错/环境没注入鉴权）时：直接用原图，但提示词里必须保留"纯浅灰或白色无缝背景、只保留一个人"。

抠完顺手看一眼：边缘是否干净、手脚是否被裁掉。缺头缺脚说明原片构图不合格，回第 1 步让用户换图。

## 2. 身份特征表（先填满，再写提示词）

**只写照片里看得见的**；看不清写"被遮挡"，禁止按常见长相脑补。每项 ≤ 12 字。

| 字段 | 要抓的点 |
|---|---|
| 脸型 | 圆 / 方 / 长 / 心形 / 菱形，下颌线是圆还是有角 |
| 眉眼 | 眉形（平直/上挑/下垂）、粗细、眼型（圆/细长/内双/单眼皮）、眼距（近/适中/宽） |
| 鼻子 | 鼻梁高塌、鼻头圆尖、鼻翼宽窄 |
| 嘴 | 唇厚薄、唇峰明显度、嘴角平/上扬/下垂 |
| 发型 | 长度、分线位置、刘海有无、卷直、发色（黑/棕/漂染） |
| 肤色 | 白皙/自然/小麦/偏黄偏红 |
| 体型 | 肩宽（宽/窄）、肌肉量、头身比（几头身）、腿长比例 |
| 服装 | 主色、版型（宽松/修身）、关键细节（抽绳、拉链、Logo 位置） |
| 配饰 | 眼镜/耳饰/项链/纹身/帽子；没有就写"无" |

**再挑 3 个"识别锚点"**——最能让人一眼认出他的特征，例如"内双+眉尾下垂+宽肩窄腰"。这 3 条必须原样出现在提示词里，是相似度的压舱石。

## 3. 姿势：用户没指定就还原原片

默认行为是**照抄照片的动作**，不是换成标准 A-pose。先读出这些再写进提示词：

- 重心在哪只脚、双脚开合
- 双肩是否一高一低、身体朝向（正面 / 3/4 / 侧面）
- 手臂位置（垂下 / 抬起 / 屈肘 / 手插兜 / 持物）
- 头部朝向与视线方向
- 手部状态（握拳 / 张开 / 自然并拢）

用户明确说要某个动作（"举起手""站直""比个耶"）才覆盖。两者冲突时以用户为准，但要说清：**换动作会降低相似度**。

**遮挡要单独处理**：照片里手或手机挡脸时，不要默默把姿势改掉。给用户两条路——换一张露脸照，或者接受"保留这个姿势、但去掉遮挡物露出脸"。这一步不问清，3D 会把手建模在脸上。

## 4. 提示词模板

**A. 默认：还原原片姿势**（`image_edit`，`model_version=seedream_5.5`，保持原图比例）

```
把这张照片里的人转成{风格}卡通角色参考图，用于 3D 建模。
身份必须还原：{脸型}、{眉形+眼型+眼距}、{鼻型}、{唇形}、{发型与发色}、{肤色}、{肩宽与体型}；
三个识别锚点必须明显保留：{锚点1}、{锚点2}、{锚点3}。
动作与姿态照原片：{重心脚与站位}、{身体朝向}、{手臂位置}、{头部朝向}。
全身入镜，从头到脚完整不裁切；四肢与身体分开、轮廓清晰不粘连；
{服装主色与版型}保留原样，简化为清晰大色块，去掉细碎纹理与褶皱；
纯浅灰无缝背景，无场景无地面阴影，无文字水印边框；
均匀柔和正面光，哑光手办质感，主体居中留少量边距；不要美化五官、不要改脸型。
```

最后那句"不要美化、不要改脸型"是压网红脸的关键，别删。

**B. 用户指定了动作**：把"动作与姿态照原片"整段换成用户要的动作，其余不变。

**C. 二次修脸**（A 出来姿态体型都对了、就是脸不像时用）

```
保持这张卡通图的姿势、体型、服装、背景完全不变，只修正头部：
把脸换成照片里这个人的五官特征——{脸型}、{眉眼}、{鼻}、{嘴}、{发型}；
比例仍是 Q 版{几头身}，不美化、不磨皮、不换成网红脸。
```

## 5. 验收：不像就返工，不要进 3D

把参考图和抠图后的原片**并排放**，遮住背景只看人，逐条过：

| 检查项 | 合格线 |
|---|---|
| 脸型轮廓 | 一眼认出是同一种脸型，下颌不圆不尖 |
| 五官位置 | 眼距、鼻嘴距离与原片一致（这是最容易跑偏的） |
| 眉眼特征 | 眉形走向与眼型能对上 |
| 发型发色 | 长度、分线、刘海方向一致 |
| 体型服装 | 肩宽比例、服装主色一致 |

**只要有一条不过，就改提示词重出**——这一步免费，比返工 3D 便宜得多。连续 3 次仍不像，说明原片信息不足（模糊、遮挡、侧脸过深），换照片比继续调词有效。

常见失败与改法：

- 脸变圆、变"网红脸" → 强调"不要美化五官、不要改脸型"，并把脸型写成具体词（方脸/长脸）
- 眼距被拉大、眼睛变大 → 在提示词里写明"眼距{近/宽}、眼睛{细长/圆}，不要放大眼睛"
- 发型被艺术化（加挑染、加卷） → 写死"发色纯黑、直发、无挑染"
- 姿势被改成标准站姿 → 把重心脚、手臂位置写得更具体，并加"不要改成 A-pose"

## 6. 边界情况

| 情况 | 处理 |
|---|---|
| 手/手机挡脸 | 先问：换露脸照，还是同姿势去掉遮挡物；不要擅自改姿势 |
| 侧脸 > 45° | 特征表只填可见的一侧，提示词加"不做对称美化"；并告知 3D 会推断另一侧 |
| 只有半身 | 提示"下半身按合理比例补出"，或建议换全身照；补出来的腿常与服装不搭 |
| 多人合影 | 先按第 1 步裁出单人再抠图；一次只做一个主体 |
| 强逆光/过曝 | 先 `enhance-image` 或让用户补拍，否则肤色和五官都读不准 |
