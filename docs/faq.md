# 常见问题

## 1. 没有方舟 API Key 能跑吗？

不能，3D 那步必须 Key。但 `create --dry-run` 和全部单元测试都不需要 Key，可以先验证参数与逻辑。

## 2. Key 会不会被上传或记录？

不会。Key 只在本地读取，直接放进 HTTP 请求头发给方舟；CLI 不写日志、不回显。放在 `.ark_key` 时建议 `chmod 600`，该文件已在 `.gitignore` 里。

## 3. 报 401 / 403 怎么办？

- **401**：Key 无效，常见原因是复制时少字符或多空格。用 `python3 scripts/ark_3d.py doctor` 确认。
- **403**：Key 有效，但账号没开通 Seed3D。去方舟控制台开通模型，再重试。不要反复重试，不会成功。

## 4. 为什么我的照片出模很差？

对照 `SKILL.md` 的质检清单：多人、缺头缺脚、严重遮挡、背景杂乱、强逆光、广角透视变形，都会直接拉低结果。这类图先裁切或重拍，比换模型有用。

## 5. 参考图看起来不像本人，还要往下走吗？

不要。卡通化最容易在"脸"上跑偏，而 3D 只会继承这个偏差。按 `references/identity-prompt.md` 的顺序处理：先抠图去背景 → 填身份特征表并挑 3 个识别锚点 → 用保姿势模板重出 → 与抠图后的原片并排比对五项。脸不对但体型姿势对，可以再走一次"只修脸"的二次编辑。三次仍不像就换照片。

## 6. 一次生成要花多久？

通常在数分钟到十几分钟，取决于任务复杂度和平台负载。`run` 默认 15 秒轮询、1500 秒超时；不想一直等就用 `create` 拿 task_id，稍后 `status` 查。

## 7. 生成失败了会退费吗？

不保证，失败也可能计费。这正是项目设计"确认闸门"和"同图默认只提交一次"的原因。

## 8. glb 打不开 / 想看效果？

glb 可拖进 Blender、Unity、Windows 3D 查看器，或任意 three.js 在线 viewer。macOS 预览 Quick Look 也支持。本项目 `make_preview.py` 会把彩色 glb 包成单文件 HTML 查看器，双击即可旋转、缩放、下载。

## 9. 支持文生 3D 吗？

本项目聚焦图生 3D。若需要文生 3D，把 `--model` 换成 `hyper3d-gen2-260112`（该模型同时支持文生），但 CLI 仍按图生路径构造请求，文生需要自行扩展请求体。

## 10. 链接 24 小时后失效，之前生成的模型会丢吗？

已下载到本地的文件不受影响，丢的只是方舟侧的临时链接。建议拿到就转存，`run` 已经自动做了这件事。

## 11. 打开模型满身"裂纹"、切片软件也补不好？

那是图生 3D 的常态：产物是**开口壳体**（实测 50 万面里有 87,699 条开放边），不是实心体。切片软件的自动修复对这种量级的缺口基本无效。用 `print_prep.py --solidify` 走泊松重建，实测能把开放边降到 0，得到水密实体。

## 12. obj 打开是白的，颜色去哪了？

两种情况：一是你打开的是补实体后的素模（泊松只重建几何，贴图必然丢）；二是原始 obj 的 `.mtl` 和 `textures/` 没跟 obj 放在一起。前者用 `bake_color.py` 把颜色搬到顶点色；后者把整个 `pbr/` 目录一起拷。

## 13. 彩色模型能直接打出颜色吗？

不建议。顶点色在切片软件里支持不一致（Bambu Studio 不吃、PrusaSlicer 部分支持）。彩色 obj/glb 适合预览和内容素材；真要彩色件，用分件换色打印或后期手涂。

## 14. 能批量跑吗？

可以。`create` / `status` / `download` 是解耦的，外层脚本自己排队即可；注意 Seed3D 2.0 是 300 RPM、5 并发。
